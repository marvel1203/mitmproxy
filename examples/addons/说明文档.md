# mitmproxy 插件示例说明文档

本目录包含了多个 mitmproxy 插件示例，这些示例展示了如何使用 mitmproxy 的各种功能。所有示例都已添加中文注释，便于中文用户理解和学习。

## 基础插件结构

### anatomy.py
一个基本的 mitmproxy 插件骨架示例。演示了如何创建一个简单的插件类，并计数经过代理的请求数量。

### anatomy2.py
使用简化脚本语法的 mitmproxy 插件示例。展示了不需要定义类，直接使用函数处理事件的方法。

## 命令系统

### commands-simple.py
演示如何向 mitmproxy 命令行添加自定义命令。
- 用法: `mitmproxy -s commands-simple.py --set addheader=true`

### commands-flows.py
演示如何处理 flows 作为命令参数。创建一个可以操作选定流量的自定义命令。

### commands-paths.py
演示如何处理文件路径作为命令参数。允许将流量信息保存到指定路径的文件中。

## HTTP 流量处理

### http-add-header.py
为每个 HTTP 响应添加一个头部字段的简单示例。

### http-modify-form.py
修改 HTTP 表单提交数据的示例。演示了如何修改或添加表单字段。

### http-modify-query-string.py
修改 HTTP 请求查询参数的示例。

### http-redirect-requests.py
将 HTTP 请求重定向到另一个服务器的示例。使用 `pretty_host` 获取请求的主机名。

### http-reply-from-proxy.py
直接从代理发送响应，而不将请求转发到目标服务器的示例。

### http-trailers.py
处理和添加 HTTP 尾部头信息(Trailers)的示例。包含对不同 HTTP 版本的兼容处理。

## 流式处理

### http-stream-simple.py
为所有 HTTP 响应启用流式处理的示例。相当于使用 `--set stream_large_bodies=1` 参数。

### http-stream-modify.py
修改流式响应内容的示例。包含关于流式修改的注意事项和最佳实践说明。

## TCP 和 WebSocket

### tcp-simple.py
处理 TCP 连接消息的示例。演示了如何修改 TCP 流量并输出日志。
- 用法: `mitmdump --tcp-hosts ".*" -s examples/tcp-simple.py`

### websocket-simple.py
处理 WebSocket 连接中的单个消息的示例。演示了如何检查、修改和丢弃 WebSocket 消息。

### websocket-inject-message.py
向运行中的 WebSocket 连接注入消息的示例。包含一个简单示例和一个使用异步任务的复杂示例。

## 流量存储和回放

### io-read-saved-flows.py
读取 mitmproxy dump 文件的示例脚本。展示了如何解析和处理保存的流量数据。

### io-write-flow-file.py
生成 mitmproxy dump 文件的示例。演示了如何选择性地保存流量，比使用 `-w` 参数更灵活。

### duplicate-modify-replay.py
复制、修改并重放 HTTP 请求的示例。演示了如何避免无限循环重放和如何使用视图功能。

## 配置选项

### options-simple.py
添加新的 mitmproxy 选项的示例。演示了如何定义自定义选项并在插件中使用它。
- 用法: `mitmproxy -s options-simple.py --set addheader=true`

### options-configure.py
响应配置变更的示例。演示了如何验证选项值并在值变更时执行操作。

## 日志和调试

### log-events.py
向 mitmproxy 的事件日志发送消息的示例。展示了不同级别的日志消息发送方法。

### nonblocking.py
使用 async 或 @concurrent 使事件钩子变为非阻塞的示例。对比了两种实现非阻塞处理的方法。

## 特殊功能

### filter-flows.py
在脚本中使用 mitmproxy 的过滤器模式的示例。

### internet-in-mirror.py
一个有趣的示例，将所有网页内容水平镜像翻转。

### shutdown.py
演示如何从插件控制关闭整个 mitmproxy 实例。
- 用法: `mitmproxy -s shutdown.py` 然后发送请求到 `http://example.com/path`

### wsgi-flask-app.py
在 mitmproxy 中托管 WSGI 应用的示例。演示了如何将 Flask 应用嵌入到 mitmproxy 中。

## 内容视图

### contentview.py
创建自定义内容视图的示例，用于特殊格式的显示。

### contentview-interactive.py
创建交互式内容视图的示例，允许在视图中编辑内容。

## 注意事项

1. 这些示例展示了 mitmproxy 的基本功能，实际应用中可能需要进行更复杂的处理。
2. 大多数示例可以组合使用，构建更强大的功能。
3. 使用 `--set` 参数可以在启动 mitmproxy 时设置选项，而不需要修改脚本。
4. 对于处理流量的插件，要注意避免创建无限循环（特别是在重放和修改流量时）。
5. 异步处理（使用 `async/await`）通常比使用 `@concurrent` 更高效，特别是在处理大量请求时。
